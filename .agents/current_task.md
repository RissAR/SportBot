# ПОТОЧНЕ ТЕХНІЧНЕ ЗАВДАННЯ (Current Task Specification)

> **Статус:** Очікування ТЗ від Чату 1 (Планування та Аналітика).

## 1. Мета та огляд
На даному етапі зафіксовано базові правила безпеки, ізоляцію секретів та робочий процес взаємодії через скіл `execute-task`.
Конкретні завдання з розробки Telegram-бота та Telegram Mini App будуть сформовані після деталізації вимог проекту.

---

## 2. Основні правила та обмеження
1. **Zero Hardcoded Secrets:** Усі секрети підтягуються виключно з `.env`. Заборонено хардкодити ключі чи дефолтні токени.
2. **Zero Scope Creep:** Виконувати виключно ті задачі, які прямо зазначені у цьому файлі.
3. **Формат звіту після виконання:**
   - Список модифікованих файлів (`File Path`).
   - Короткий опис виконаних дій.
   - Єдина команда для git: `git add . && git commit -m "..." && git push origin main`.
