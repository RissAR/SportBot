# ТЕХНІЧНЕ ЗАВДАННЯ: Редизайн та окультурення UI/UX Telegram Mini App

## 1. Мета та огляд
Усунути всі візуальні та ергономічні недоліки, виявлені під час ручного тестування:
1. **Типографіка:** Повністю прибрати моноширинний «програмістський» шрифт (`font-mono`) з усіх карток, описів та рівнів прогресії. Замінити його на сучасний спортивний Sans-Serif (Apple SF Pro / Inter).
2. **Скролбар категорій:** Приховати нативний повзунок скролу на чіпсах категорій (`All`, `Push`, `Pull`, `Legs`, `Core`, `Cardio`). Забезпечити чистий свайп пальцем (`touch-pan-x` + `no-scrollbar`).
3. **Компактизація головного екрана (Усунення «простирадла»):**
   - Перетворити розминку (Warm-up) та заминку (Cool-down) на **Смарт-Акордеони** (за замовчуванням згорнуті у компактні плашки з кнопкою `[Mark Done ✓]` та шевроном розгортання `▼`).
   - На картках вправ залишити лише ключову інформацію (назва, підходи, цільові повторення, темп `3-1-1`, великі зручні кнопки сетів). Довгі описи біомеханіки та поради безпеки винести під елегантну кнопку `[ℹ️ Info]`, яка відкриває модальне вікно.
4. **Загальний візуальний баланс:** Заспокоїти палітру (прибрати світлофорні кольори терміналу), вирівняти шапку, зробити дизайн монолітним, преміальним та спортивним.
5. Зібрати оновлений фронтенд (`npm run build`) та оновити роботу сервера/тунелю для повторного ручного тестування.

## 2. Покрокові технічні вимоги

### БЛОК 1. CSS утиліти та приховування скролбара (`frontend/src/index.css`)
1. Додати глобальні утиліти для приховування смуги прокрутки при збереженні функції скролу:
   ```css
   @layer utilities {
     .no-scrollbar::-webkit-scrollbar {
       display: none;
     }
     .no-scrollbar {
       -ms-overflow-style: none;
       scrollbar-width: none;
     }
   }
   ```
2. Перевірити базовий шрифт: `-apple-system, BlinkMacSystemFont, "Inter", "Segoe UI", Roboto, sans-serif`.

---

### БЛОК 2. Окультурення GuideTab (`frontend/src/components/GuideTab.tsx`)
1. **Категорії:**
   - Додати клас `no-scrollbar` до контейнера `overflow-x-auto`.
   - Забезпечити плавний скрол без видимого повзунка.
2. **Типографіка та Progression Tiers:**
   - **Повністю видалити `font-mono`.**
   - Замість термінального коду `Light: ...`, `Medium: ...`, `Hard: ...` зробити чистий блок із 3 акуратними картками/бейджами:
     - Бейджі `Light`, `Medium`, `Hard` у спокійних стильних тонах (без кислотно-зелених/жовтих кольорів).
     - Чіткий текст повторень та темпу нормальним шрифтом (`text-sm text-zinc-200`).
3. **Заголовки секцій:**
   - Замінити моноширинні заголовки на лаконічні Sans-Serif заголовки з нормальним трекінгом (`text-xs font-bold uppercase tracking-wider text-zinc-400`).

---

### БЛОК 3. Редизайн та компактизація WorkoutTab (`frontend/src/components/WorkoutTab.tsx`)
1. **Смарт-Акордеон Розминки (Dynamic Warm-up):**
   - Додати локальний стан: `isWarmupOpen: boolean` (за замовчуванням `false`), `isWarmupDone: boolean`.
   - Верхня плашка:
     - Іконка `⚡️`, заголовок `Dynamic Warm-up`, час `8–10 min • 5 drills`.
     - Кнопка швидкої відмітки `[Mark Done ✓]` (зеленіє при виконанні).
     - Кнопка/шефрон `▼`/`▲` для розгортання повного списку вправ тільки при потребі.
     - При натисканні `Mark Done` — автоматично згортається, щоб звільнити місце під вправи.
2. **Компактні картки вправ:**
   - Картка містить:
     - Назву вправи (напр. `Parallel Bar Dips`) та категорію.
     - Стильний рядок параметрів: `Target: 4 sets × 12 reps` • `Tempo: 3-1-1` • `Rest: 60s`.
     - Кнопку `[ℹ️]` праворуч від назви — при натисканні відкриває красиву модалку з повним описом біомеханіки та порадами безпеки для 85 кг.
     - **Рядок підходів (Sets):** зручні великі прямокутні кнопки для тапу пальцем:
       - Невиконаний: темний графіт (`bg-zinc-900/80 border border-zinc-700/60 text-zinc-300`).
       - Виконаний: яскравий червоний градієнт із галочкою (`bg-gradient-to-r from-red-600 to-rose-700 text-white font-bold shadow-md`).
       - При тапі — запуск Rest Timer HUD на 60с + Haptic вібрація.
3. **Смарт-Акордеон Заминки (Cool-down & Recovery):**
   - За замовчуванням згорнуто: плашка `🧘 Cool-down & Recovery (5–7 min • 4 stretches)` + кнопка `[Mark Done ✓]`.
   - Розгортається лише при натисканні на шеврон.
4. **Головна кнопка фінішу:**
   - Фіксована/плаваюча або акуратно розташована знизу червона кнопка `🔥 COMPLETE WORKOUT (DAY X)`.

---

### БЛОК 4. Модальне вікно техніки вправи (Exercise Detail Modal)
1. Створити легке спливаюче модальне вікно (або Bottom Sheet) у `WorkoutTab`:
   - Назва вправи.
   - Біомеханіка та траєкторія руху.
   - Блок `Safety Tips for 85 kg Bodyweight`.
   - Кнопка `Close`.

---

### БЛОК 5. Збірка та повторний запуск
1. Зібрати фронтенд: `cd frontend && npm run build` (переконатися у відсутності помилок TypeScript/Vite).
2. Переконатися, що бекенд та Cloudflare тунель роздають оновлені файли на порті 8000.
3. Надати звіт із посиланням на тунель для перевірки оновленого дизайну на телефоні.

## 3. Критерії приймання та верифікація (Acceptance Criteria)
1. **Шрифти:** У додатку немає жодного елемента з моноширинним шрифтом (`font-mono`) у контентних блоках. Уся типографіка чиста, спортивна (Sans-Serif).
2. **Скролбар:** Горизонтальний скрол категорій працює плавно пальцем, сірий нативний повзунок повністю відсутній.
3. **Компактність:** Головний екран не має нескінченного скролу; розминка і заминка згорнуті в компактні плашки; картки вправ лаконічні та фокусуються на сетах.
4. **Стабільність:** Код збирається `npm run build` з нулем помилок.
5. **Формат звіту:** Список змінених файлів та єдина команда git:
   `git add . && git commit -m "..." && git push origin main`.
